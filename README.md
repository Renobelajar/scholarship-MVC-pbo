# Scholarship MVC PBO

MVC-based scholarship management system using Object-Oriented Programming concepts.

## Features
- Student data management
- Scholarship registration system
- Scholarship selection process
- Applicant status monitoring
- MVC architecture implementation

## Technologies
- Java
- MVC Architecture
- OOP Concept

## System Functions
- Add student data
- Update scholarship information
- Display applicant data
- Manage scholarship selection
- Monitor scholarship status

## Concepts Used
- Model View Controller (MVC)
- Object-Oriented Programming
- Class & Object
- Encapsulation
- Data Management
